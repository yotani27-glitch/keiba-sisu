# 地方競馬データの収集と基礎分析

ネット競馬（nar.netkeiba.com）の地方競馬レース結果を集めて、予想ノウハウを
実測で作るためのツールです。中央の優先指数と同じ考え方（大量の実績で検証し、
前半・後半で再現するものだけを採用する）を、地方でもやれるようにするのが目的です。

中央で使っている TARGET の指数（Ｆ・Ｓ・arms2 など）は地方をカバーしていないため、
地方では**レース結果そのもの（着順・人気・通過順・上がり・騎手・枠など）から
指標を自作する**ことになります。

## 利用上の注意（必ず守ること）

ネット競馬の利用規約（2026年11月時点で確認）に基づく制約です。

| 規約 | 内容 | このツールでの対応 |
|------|------|------------------|
| 第14条 | 取得データは私的利用の範囲まで。不特定多数が見られる場所に置くのは目的を問わず禁止 | 保存先 `nar_data/` は `.gitignore` 済み。**公開リポジトリ・GitHub Pages・Xに生データを載せない** |
| 第15条 | 営利目的の利用は禁止 | 個人の検討用に限る |
| 第16条12号 | 設備の運営に支障を与える行為の禁止 | アクセス間隔は既定3秒（2秒未満は設定不可）。取得済みページは保存して二度と取りに行かない |

アクセスが多すぎると一時的に接続を拒否されることがあります。その場合ツールは
自動で止まるので、数時間〜1日おいてから同じコマンドを打てば続きから再開します。

**会社のネットワークでは実行しないこと。** 競馬サイトへの接続はフィルタで止められています
（実行すると `SSL: CERTIFICATE_VERIFY_FAILED` という証明書エラーになります）。このエラーが
出たときは、ツールは再試行せずにすぐ止まります。証明書の確認を無効にするなど、フィルタを
すり抜ける設定はしないでください。

## 使い方

Python 3.8以上があれば、追加インストールなしで動きます。`collect.py`・`baseline.py` は
同じフォルダに置き、PowerShellでそのフォルダへ移動してから実行します。データは同じフォルダの
`nar_data\` に作られます。

```powershell
cd "（collect.py を置いたフォルダ）"
```

### 1. 結果を集める

```powershell
# 南関東4場（浦和・船橋・大井・川崎）の2025年以降
python collect.py --start 20250101 --venues 南関東

# 全場（ばんえい以外）の昨日分だけ
python collect.py --start 20261102 --end 20261102
```

- `--venues` には競馬場名（`大井,川崎`）、グループ（`南関東` `岩手` `東海` `兵庫`）、場コード（`44`）が使えます。省略時はばんえい以外の全場
- `--end` を省略すると昨日まで。新しい日付から古い日付へ順に取得します
- 途中で止めても（Ctrl+C）、次回は取得済みの分を飛ばして続きから再開します
- 最後に `nar_data/` へ3つのCSVを作り直します

**所要時間の目安**（間隔3秒）: 通信時間を含めて1レースにつき約3.7秒（試験時の実測）。

| 対象 | 1年あたりのレース数（概算） | 1年分の所要時間 |
|------|------|------|
| 南関東4場 | 約3,000 | 約3時間 |
| 全場（ばんえい除く） | 約13,000 | 約13時間 |

一晩に1年分ずつ、のように数回に分けて実行するのがおすすめです。

### 2. 基礎傾向を集計する

```powershell
python baseline.py                  # 集めた全データ
python baseline.py --venues 南関東  # 競馬場を絞る
```

画面に表示し、`nar_data/reports/baseline.md` にも保存します。各表に
**前半・後半の成績を並べている**ので、両方で同じ傾向が出ているものだけを
信用してください。頭数30未満のセルは「-」になります。

集計している項目:

1. 競馬場別のデータ量
2. 人気別の成績（勝率・複勝率・単勝/複勝回収率）
3. 競馬場別の1番人気の信頼度
4. 4角位置別の成績（競馬場ごとの先行有利度。レース後の情報）
5. 前走の4角位置（＝先行力）別の今走成績（レース前に使える指標）
6. 前走着順・前走上がり順位別の今走成績
7. 枠番別の複勝率（競馬場別）
8. 騎手（騎乗数上位20名）

### CSVだけ作り直す

解析部分を直したときや、Excelで開いていてCSVを書き込めなかったときは、取得せずに
キャッシュからCSVだけ作り直せます。

```powershell
python collect.py --build-only
```

## 出力ファイル（`nar_data/`、すべて非公開）

| ファイル | 1行 | 主な列 |
|---------|-----|-------|
| `races.csv` | 1レース | 日付、競馬場、R、レース名、クラス、芝ダ、距離、回り、天候、馬場、頭数、発走時刻、1着賞金、ラップ、前半3F、後半3F（ラップ類は公開している南関東などのみ） |
| `results.csv` | 1頭 | 着順、枠、馬番、馬ID、馬名、性齢、斤量、騎手ID・騎手名・減量記号、タイム（秒）、着差、人気、単勝オッズ、上がり3F、所属、調教師、馬体重・増減、コーナー通過順（例 `5-7-2-1`）、4角位置 |
| `payouts.csv` | 1払戻 | 券種、組番、払戻金、人気（単勝〜3連単の全券種） |
| `cache/` | — | 取得したページ（必要部分だけ圧縮保存）。**1日分＝1ファイル**（`cache\2026\20261102.json.gz`）なので、OneDrive上に置いてもファイル数は1年で365個程度 |

文字コードはUTF-8（BOM付き）なので、Excelでそのまま開けます。ただし収集中にExcelで
開いたままにしているとCSVを上書きできないので、閉じてから `--build-only` を実行してください。

## 今後の進め方（案）

1. **データを貯める**: まず南関東（または普段買う競馬場）の2〜3年分
2. **基礎傾向の把握**: `baseline.py` で、競馬場ごとの人気の信頼度・先行有利度・枠の有利不利を確認
3. **地方版の優先指数**: 前走の先行力・着順・上がり順位・騎手成績・同コース実績・間隔などをレース内で順位化し、
   中央と同じく条件付きロジットで重みを推定（古い期間で学習 → 新しい期間で検証）
4. **当日の運用**: 出馬表と馬柱（`shutuba_past.html`、近5走・中央時代の成績・血統・脚質を含む）を
   レース当日に取得して指数を計算し、webappで表示
