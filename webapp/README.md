# 指数ビューア

TARGET frontier の外部指数取込フォーマット（`<ラベル><YYYYMMDD>.csv` を束ねたZIP、またはCSV単体）を、
TARGETソフトに取り込まずにブラウザだけで一覧表にするための静的アプリです。サーバー送信なし、CDN依存なし。

## 対応データ形式

- ファイル名: `00tua20260808.csv` のように `<ラベル><日付8桁>.csv`（ラベル例: `00`,`1`〜`11`,`gallop`,`GYN` など、任意の英数字ラベルを自動認識）
- 1行の中身: `18桁ID` + タブ or カンマ + `スコア値`
  - 18桁ID = `YYYYMMDD`(8) + `場所コード`(2) + `開催回`(2) + `開催日`(2) + `R`(2) + `馬番`(2)
- 複数ラベルのCSVをまとめたZIPをそのまま渡してもOK（ブラウザ内でZIP展開）

馬名は指数CSV自体には含まれないため、`name<日付8桁>.csv`（例: `name20260808.csv`）という
専用ファイルを同じフォルダに置くと自動結合されます。中身は他の指数CSVと同じ「18桁ID,値」形式ですが、
値の部分に馬名文字列を入れます（ヘッダー行なし、UTF-8、例: `202608080101050101,ルージュエピック`）。
このファイルが無ければ、従来通り「場所・R・馬番」単位の表示になります。

## 使い方

1. `index.html` を Chrome または Edge で開く（`file://` 直接開き、または簡易サーバーどちらでも可）
   ```powershell
   python -m http.server 8000
   ```
2. 「フォルダを選択して読み込み」を押し、指数CSV／ZIPが置かれているフォルダを選択
3. 次回以降は同じボタンを押すだけで再読み込みされます（File System Access API 対応ブラウザの場合、フォルダ選択が省略されます）
4. 「レース一覧」タブで優先指数と堅さ判定を確認（既定は最新日付のみ表示）。
   「指数テーブル」タブでは従来通り、日付・場所・R・表示列（値/順位）で絞り込み、
   列ヘッダーでソート、CSVエクスポートが可能です

Chrome/Edge以外（Safari/Firefoxなど）では毎回フォルダ選択ダイアログが出る簡易モードで動作します。

### PCで公開しておけばiPhoneでは何も選ばなくてよい

PC側で週次ZIPを取り込んだあと、リポジトリ直下で次を実行して push すると、
`webapp/data/` に指数が置かれます。

```powershell
python publish_data.py            # 指数フォルダの最新日を書き出す
python publish_data.py 20260809   # 日付を指定
git add webapp/data && git commit -m "指数データを更新" && git push
```

以降はどの端末でもURLを開くだけで最新データが表示されます。ファイル選択は不要です。
前回と同じ内容ならダウンロードし直さずキャッシュを使い、新しい日付が増えたときだけ取り込みます。
手動で取り直したいときは「**最新データを取得**」を押してください。

**注意**: このリポジトリは公開されているため、`webapp/data/` に置いた指数は誰でも取得できます。
出力しているのは優先指数の計算と表示に必要な6ラベル（Ｓ・Ｆ・arms２・LVL2・予想人気・厩舎Finish-Up）と馬名だけです。

### 一度読み込めば次回から選び直し不要

読み込んだ指数はブラウザ内（IndexedDB）に保存され、次に開いたときは**ファイルを選ばずにそのまま表示**されます。
当日入力した人気や、指数テーブルの表示列の選択も一緒に残ります。

新しい週のデータを読み込めば上書きされます。消したいときは「**保存データを消す**」を押してください。

保存しているのは指数の生の値だけで、順位や優先スコアは開くたびに計算し直しています。
そのため、あとから重みや対象指数を変えても古い結果が残りません。

### iPhone / iPad で使う

iOSはフォルダ選択に対応していない（`showDirectoryPicker`が無く、`webkitdirectory`も効かない）ため、
ファイルを直接選ぶ経路を用意しています。

1. 「**ZIP/CSVを選ぶ**」を押して、次の2つを**まとめて選ぶ**（iOSのファイルアプリは複数選択できます）
   - `2tua20260809.zip` … 週次の指数ZIP。これだけでも優先指数と堅さ判定は出ます（Ｆ・Ｓ・arms・LVL2 の4指数）
   - `name20260809.csv` … 馬名。**選ばないと馬番だけの表示**になります
2. 厩舎Finish-Upも使いたい場合は「**厩舎Finish-Upを追加**」から日付のCSVを選ぶ
   → 5指数に増えます。既に読み込んだデータは消えず、重ねて追加されます

ZIPは`指数フォルダ`、馬名は`競争馬名`フォルダと置き場所が分かれているので、
あらかじめ同じフォルダ（iCloud DriveやOneDriveなど）にコピーしておくと一度で選べます。
馬名を読み込まずに終わった場合は「馬名なし」と通知され、必要なファイル名が表示されます。

厩舎Finish-Upが別ボタンなのは、ファイル名が `20260809.csv` と日付だけで、
フォルダ名（＝指数名）が取れないためです。「ZIP/CSVを選ぶ」から選ぶと
指数名が判別できず読み飛ばされ、その旨が通知されます。

4指数と5指数の差は優先指数1位馬の勝率で25.1%対25.4%なので、
厩舎Finish-Upが無くても実用上の支障はありません。

## レース一覧（優先指数・堅さ判定）

読み込むと最初に開くタブ。各レースを「優先指数」で並べ替えたうえで、レースの堅さを3段階で表示します。
確定オッズを待たずに、週次でダウンロードしたZIPだけで判定できます。

### 優先指数

2022〜2026年の15,414レース・211,848頭を条件付きロジットで学習して決めた重みで、複数の指数を1本化したもの。

```
優先スコア =（4×Ｆ指数 + 3×Ｓ指数 + 2×arms指数２ + 2×LVL2 + 2×厩舎Finish-Up）÷ 13
※各項はレース内で正規化した順位 =（出走頭数 − 順位）÷（出走頭数 − 1）
```

- 効かないと確認できた指数（坂路血統・持ち時計血統・コース連動・血統連動・バランス・坂路調教）は使いません。
  5年間ずっと1位馬の勝率がランダム基準7.3%と区別できず、混ぜるとむしろ精度が落ちるためです
- そのレースの全馬に揃っている指数だけを使い、重みをその分だけ再正規化します。
  厩舎Finish-Up（2025年8月中旬以降のみ）やLVL2（2022年に無し）が欠けていても計算できます
- Ｆ指数とＳ指数は重みの6割強を占めるため、この2つが欠けているレースは算出しません
- カード右上の「◯指数」は、そのレースで実際に使えた指数の数です

### スコアの数値と「1-2位差」

順位だけでなく**スコアの数値そのものにも情報があります**。同じ優先1位でも、
スコアが高い馬ほどよく勝ちます（2022〜2026年・15,367レースの実測）。

| 優先1位馬のスコア | 勝率 | 複勝率 |
|------|------|--------|
| 0.94〜1.00 | 33.5% | 64.0% |
| 0.90〜0.94 | 26.4% | 57.9% |
| 0.87〜0.90 | 24.2% | 55.1% |
| 0.84〜0.87 | 22.4% | 52.9% |
| 0.61〜0.83 | 21.0% | 49.7% |

出走頭数で分けても傾向は変わらないので、頭数の影響ではありません。

### 上位3頭の並び方（独走・2強・団子）

1位と2位の差、2位と3位の差を組み合わせると、レースの型が見えてきます。
カードの見出しに表示しています（1-2位差・2-3位差とも中央値0.056／0.043が境）。

| 型 | 条件 | 優先1位馬の勝率 | 複勝率 |
|----|------|----------------|--------|
| 🟢 独走 | 1位が2位から抜け、2位も3位以下から抜けている | 30.7% | 61.4% |
| 🔵 2強 | 1位と2位は僅差だが、2頭とも3位以下から抜けている | 23.3% | 53.9% |
| 🔴 団子 | 1位・2位・3位が僅差で並んでいる | 19.5% | 48.9% |

「1位が2位に競り勝っているように見えても、実は上位2頭がまとめて3位以下から
浮いているだけ（2強）」というケースを区別できるのがポイントです。2強のときは
**優先2位馬の成績も上がります**（勝率21.4%、全レース平均17.8%）。1位固定では
なく、上位2頭を軸に見たほうがいいレースの目安になります。

この2つに当てはまらない場合（バッジ非表示）は、1位のスコアだけ抜けていて
2-3位差は詰まっている、といった中間的な形です。

### 堅さ判定

優先指数の上位2頭と、予想人気（GYN）の上位2頭が何頭重なるかで分類します。

| 表示 | 一致 | 優先1位馬の勝率 | 複勝率 |
|------|------|----------------|--------|
| 堅そう | 2頭 | 30.1% | 66.0% |
| 標準 | 1頭 | 24.6% | 54.6% |
| 荒れそう | 0頭 | 17.1% | 45.2% |

2026年の1,973レースでの実測値です。GYNはレース前に分かるのが利点です。
GYNが読み込まれていないレースは「判定不可」と表示されます。

### 当日の人気で判定し直す

各レースカードの下部に「当日の人気」欄があります。レース当日にJRAサイトなどで
確定オッズを見て、**人気1位と2位の馬番**を入れると、判定がそちらに切り替わります。
確定オッズ基準のほうが分離が鋭くなります。

| 表示 | 一致 | 優先1位馬の勝率 | 複勝率 |
|------|------|----------------|--------|
| 堅そう | 2頭 | 31.9% | 64.9% |
| 標準 | 1頭 | 24.8% | 55.0% |
| 荒れそう | 0頭 | 11.0% | 35.1% |

2022〜2026年の15,367レースでの実測値です。荒れそうの判定が17.1%→11.0%まで下がり、
堅そうとの差が3倍近くに開きます。

- 入力したレースは枠線が太くなり、判定バッジに「当日人気基準」と表示されます
- 該当する馬は一覧の中で背景色が付きます
- 入力内容はブラウザに保存されるので、再読み込みしても消えません
- 「×」ボタンで消すと、予想人気(GYN)基準の判定に戻ります

#### 入力した人気を他の端末へ渡す

「**共有リンクを作る**」を押すとリンクがクリップボードにコピーされます。
そのリンクを他の端末（LINEのKeepメモやメールなど、自分に送れる手段なら何でも）で開くと、
入力済みの当日人気がそのまま反映されます。

PCでまとめて入力しておいてiPhoneで見る、という使い方ができます。
人気は数字だけなので36レース分でもリンクは400文字程度に収まり、サーバーは不要です。
リンクの `#` 以降にデータが載るため、アクセス先のサーバーには送信されません。
取り込むと自動でURLから消えるので、再読み込みで二重に適用されることもありません。

**注意**: これは的中率を測るための指標です。優先指数1位の単勝回収率は約80%で、単勝の払戻率とほぼ同じでした。
機械的に買って利益が出るものではなく、検討の順番を決めたり、本命の信頼度を測るために使ってください。

## 指数の見方

- 「値」= CSVに入っている素点そのまま
- 「順位」= 同じ日付・場所・Rの中で、値の高い順に付けたアプリ内の順位（同値は同順位）。GYN(予想人気順)のように値自体がすでに順位のラベルは、順位列を作らず値のみ表示
- 1位=黄色、2位=青、3位=緑で値・順位の両セルに色付け
- ラベルが多数あるため、上位ラベルのみ表示したい場合は「表示列」から絞り込んでください
